# نمادهای اختصاصی رصام

از ۲۰۲۶/۱۰/۱۸، تصویر «Teal Chat Bubble Data Icon.png» که صاحب پروژه فرستاده
نماد اصلی است. نسخهٔ اصلی بدون تغییر در `logo-source.png` نگه‌داری می‌شود.
در ۲۰۲۶/۱۰/۱۹، پس‌زمینه با ابزار imagegen حذف و نسخهٔ دارای کانال شفافیت در
`logo-transparent.png` نگه‌داری شد. تصویر اصلی حفظ شده است؛ نسخهٔ استخراج‌شده
منبع ساخت آیکون‌هاست و قاب آن به viewBox مربع ۸۵۰ پیکسلی محدود می‌شود.

`mark.svg` پوشش SVG همان تصویر PNG (نه بردار بازطراحی‌شده) و `icons.json` منبع ۱۹ آیکون عملیاتی‌اند. خط‌ها و گوشه‌های
آیکون‌ها هندسی و ضخامت خط روی شبکهٔ ۲۴ واحدی ۱٫۷ است. نماد اصلی رنگ ثابت دارد؛
آیکون‌های عملیاتی با CSS mask رنگ متن را می‌گیرند و در دکمهٔ روشن/تیره خوانا می‌مانند.
آیکون‌های تزئینی `aria-hidden` دارند و متن دکمه‌ها حفظ شده است. نشان وضعیت و شمارهٔ
قدم‌ها معنایی‌اند؛ لازم نیست همهٔ نشانه‌های متنی با تصویر جایگزین شوند.

## بازتولید

از ریشهٔ پروژه، Node برای ابزار طراحی کافی است؛ وابستگی تازه‌ای به اجرای محصول اضافه نمی‌شود:

```powershell
npm install --prefix .codex/tools/brand --no-audit --no-fund --save-exact @resvg/resvg-js@2.6.2
node assets/brand/build.mjs
```

اسکریپت ابتدا پوشش SVG را از `logo-transparent.png` می‌سازد؛ خروجی PNG، ICO ویندوز و ICNS مک از همان تصویر رندر می‌شوند. رابط‌ها PNG را نمایش می‌دهند؛ `rasam.ico` اندازه‌های ۱۶، ۲۰، ۲۴، ۳۲،
۴۸، ۶۴، ۱۲۸ و ۲۵۶ را دارد. PyInstaller آیکون فایل اجرایی و Inno آیکون نصب‌کننده را
از همین فایل می‌گیرند؛ میان‌برها و نمایش حذف برنامه از فایل اجرایی استفاده می‌کنند.

اسکریپت، نسخهٔ یکسان نماد، PNG، `brand.css` و پوشهٔ `icons/` را در `website/public`،
`admin_panel/public` و `rasam/desktop/static` می‌سازد. این کپی‌های خروجی در Git هستند
تا ساخت عادی و CI به ابزار طراحی نیاز نداشته باشند. پس از تغییر منبع، اسکریپت را
دوباره اجرا کنید؛ فایل‌های خروجی را جداگانه ویرایش نکنید.

در پنل فقط نام آیکون‌های مشخص در فهرست عمومی مجازند؛ صفحه‌های خصوصی و فایل‌های راز
همچنان از مسیر فایل ثابت قابل دریافت نیستند. نمادهای موجود در نمودار ثالث Plotly،
نشان تجاری سرویس‌های دیگر و آیکون‌های خود ویندوز جزو این مجموعه نیستند.

## نتیجهٔ بررسی — ۲۰۲۶/۱۰/۱۸

- ۱۱۹ تست مرتبط Python (رومیزی، بسته‌بندی، پنل و عملیات لایسنس) و ۸ تست Node سایت موفق‌اند.
- ۲۲ دارایی در هر سه رابط بایت‌به‌بایت یکسان‌اند؛ دریافت HTTP همهٔ آن‌ها در دو Worker
  عمومی و اجرای محلی رومیزی موفق بود. صفحهٔ خصوصی پنل همچنان نشست لازم دارد و مسیر
  ناشناختهٔ `icons/panel.html` عمومی نشده است.
- آیکون ICO با System.Drawing ویندوز در اندازهٔ ۳۲ خوانده شد؛ هشت تصویر داخل منابع
  PE فایل اجرایی و نصب‌کننده با منبع ICO تطبیق بایتی دارند.
- بستهٔ 0.1.2 در پوشهٔ مستقل `exports/windows-branding-0.1.2/` ساخته شد؛ اجرای EXE،
  دریافت فایل‌های نماد و خروج امن موفق بودند. SHA-256 نصب‌کننده با فایل همراه یکسان است.
  نصب فعلی کاربر تغییر نکرد؛ آزمایش ارتقا/میان‌بر نصب قبلی یا Windows تازه انجام نشد.
- ظاهر سایت، پنل و صفحهٔ فعال‌سازی رومیزی در مرورگر بررسی شد؛ خطای بارگذاری در سایت
  و پنل دیده نشد. عرض‌های مؤثر ۶۵۲ و ۱۲۸۰ سرریز صفحه نداشتند. کنترل اندازهٔ ۳۹۰
  ابزار مرورگر اعمال نشد؛ آزمون آن اندازه در این نوبت تأیید نشده است.

شواهد محلی در `exports/brand-pytest.log`، `brand-assets-acceptance.json`،
`brand-windows-icons.json` و `rasam-brand-*.png` هستند. تصویر مجموعه
`exports/rasam-brand-gallery.png` و پیش‌نمایش HTML آن در `exports/brand-gallery/` است.
سایت و پنل منتشر شدند؛ فرادادهٔ عمومی نسخه/دانلود همچنان به خروجی قبلی 0.1.1
اشاره دارد و دانلود معوق است. اعلام 0.1.2 روی gateway فقط پس از انتشار مجاز فایل است.

برای مک، `rasam.icns` تصاویر ۱۶ تا ۱۰۲۴ پیکسل را در قالب ICNS دارد؛ ابزار ساخت مک
از همین فایل استفاده می‌کند. ساختار و ابعاد تصاویر در ویندوز بررسی شده‌اند؛ نمایش
Finder/Dock باید در قدم ۴۳ روی مک تأیید شود.
