# فضای سازمانی رصام

این وب‌اپ جدا از نصب رومیزی است. حساب‌ها، اعضا، تنظیمات اتصال، گفتگوها و سهمیه
روی ذخیره‌ساز مرکزی قرار می‌گیرند؛ ورود همان حساب در دستگاه دوم همان گفتگوها را
می‌آورد. حساب و تاریخچهٔ نصب قبلی خودکار منتقل نمی‌شوند. دیتابیس اصلی مشتری
کپی نمی‌شود، اما سؤال، پاسخ، ردیف‌های نتیجه و نمودار در تاریخچهٔ مرکزی ذخیره می‌شوند.

مدیر کل سازمان و مقصدهای مجاز دیتابیس را تعریف می‌کند و لینک دعوت مدیر سازمان
می‌گیرد. مدیر سازمان اتصال فقط‌خواندنی، توضیح داده‌ها، منابع مجاز، دعوت و سهمیهٔ
اعضا را مدیریت می‌کند. لینک دعوت یک‌بارمصرف و هفت‌روزه است؛ آن را خصوصی ارسال
کنید. ارسال ایمیل و تأیید مالکیت ایمیل از طریق سرویس ایمیل هنوز پیاده نشده است؛
ایمیل یکتا و دعوت خصوصی جای ورود با Google نیست. حساب موجود برای پذیرش دعوت
باید ابتدا وارد شود؛ رمز آن هرگز با دعوت عوض نمی‌شود.

مشاهدهٔ متن گفتگوهای اعضا پیش‌فرض خاموش است. فقط مدیر کل رصام می‌تواند این
امکان را برای هر سازمان فعال یا لغو کند؛ مدیر سازمان خودش مجوز نمی‌دهد. اعضا
وضعیت را در رابط می‌بینند؛ مشاهدهٔ نظارتی ثبت می‌شود و فقط خواندنی است.

## اجرای محلی با حساب واقعیِ آزمایشی

از ریشهٔ مخزن در محیط مجازی:

```powershell
python -m pip install -r requirements-organization.txt
$env:RASAM_ORG_LOCAL='1'
$env:RASAM_ORG_HOME="$env:LOCALAPPDATA\RasamOrganizationDev"
$env:RASAM_ORG_ORIGIN='http://127.0.0.1:8795'
python organization.py init --email admin@example.com --name 'مدیر رصام'
python organization.py serve
```

`init` رمز را تعاملی می‌گیرد؛ حداقل ۱۲ کاراکتر. کلید رمزگذاری محلی در انبار رمز
سیستم و اطلاعات در `organizations.sqlite3` مسیر انتخابی می‌مانند. این مسیر را
با پوشهٔ دادهٔ نسخهٔ رومیزی یکی نکنید. صفحهٔ ورود روی نشانی بالا باز می‌شود.
نمونهٔ پیش‌نمایش فعلی با پاسخ ساختگی، مسیر تولید نیست و نباید روی اینترنت منتشر شود.

برای اتصال: در مدیریت کل، سازمان بسازید و میزبان مجاز را دقیق وارد کنید؛ سپس با
دعوت مدیر وارد شوید، فرم اتصال را کامل و «آزمایش اتصال امن» را بزنید. منابع را
انتخاب و ذخیره کنید؛ برای اعضا منابع و سقف روزانه تعیین کنید. آزمون اتصال مدل
مصرف نمی‌کند؛ فرستادن سؤال پس از تنظیم مدل ممکن است چند فراخوانی مدل داشته باشد.

## استقرار آزمایشی Cloudflare + Render رایگان

این مسیر آماده‌سازی شده، هنوز مستقر نشده است. فایل `render.yaml` پلن `free` و
انتشار خودکار خاموش دارد. سرویس Python پس از بیکاری می‌خوابد؛ شروع نخست کند و
دیسک آن موقت است. اطلاعات پایدار در D1 می‌مانند. هیچ تضمین استفادهٔ عملیاتی یا
پشتیبان‌گیری سازمانی از این نمونه نتیجه نمی‌شود. اشتراک پولی فعال نکنید.

۱. کد مرورشده را با مجوز صاحب مخزن به GitHub بفرستید و Render را به همان مخزن
متصل کنید. ایجاد حساب، پذیرش شرایط و مجوز دسترسی مخزن را خود صاحب حساب انجام دهد.

۲. دارایی‌ها و D1 تازه بسازید؛ از دیتابیس لایسنس یا پنل مدیریت قبلی استفاده نکنید:

```powershell
python organization_portal/build_assets.py
node gateway/node_modules/wrangler/bin/wrangler.js d1 create rasam-organizations --config organization_portal/cloudflare/wrangler.toml
```

شناسهٔ برگشتی را جای placeholder در `organization_portal/cloudflare/wrangler.toml`
بگذارید. سپس:

```powershell
node gateway/node_modules/wrangler/bin/wrangler.js d1 migrations apply rasam-organizations --remote --config organization_portal/cloudflare/wrangler.toml
node gateway/node_modules/wrangler/bin/wrangler.js secret put STORAGE_KEY --config organization_portal/cloudflare/wrangler.toml
node gateway/node_modules/wrangler/bin/wrangler.js secret put BACKEND_KEY --config organization_portal/cloudflare/wrangler.toml
```

دو راز مستقل و تصادفی، هر کدام حداقل ۴۰ کاراکتر، در مدیر رمز بسازید و در ورودی
تعاملی وارد کنید؛ در کد، فایل پلن، چت یا آرگومان فرمان نگذارید. همان مقدار هر
کدام در متغیر متناظر Render قرار می‌گیرد. این‌ها رمز کاربر یا کلید مدل نیستند.

۳. متغیرهای Render:

| متغیر | مقدار |
|---|---|
| `RASAM_ORG_ORIGIN` | نشانی HTTPS نهایی Worker، بدون مسیر |
| `RASAM_ORG_STORAGE_URL` | همان نشانی HTTPS Worker |
| `RASAM_ORG_BACKEND_KEY` | همان `BACKEND_KEY` در Worker |
| `RASAM_ORG_STORAGE_KEY` | همان `STORAGE_KEY` در Worker |
| `RASAM_ORG_MASTER_KEY` | کلید Fernet تولیدشده توسط Blueprint؛ نسخهٔ امن پشتیبان بگیرید |
| `RASAM_ORG_LLM_API_KEY` | کلید اختصاصی مدل برای بخش سازمانی، فقط وقتی آزمون مدل مجاز است |
| `RASAM_ORG_LLM_BASE_URL` | نشانی سازگار با OpenAI طبق تنظیم ارائه‌دهنده |
| `RASAM_ORG_LLM_MODEL` | نام مدل ارائه‌دهنده |

متغیرهای دیگر در Blueprint هستند. کلید رمزگذاری را در انتشار مجدد عوض نکنید؛
بدون کلید قبلی، رمز اتصال‌های ذخیره‌شده قابل بازیابی نیست. فایل `.env` شخصی
نصب رومیزی خوانده نمی‌شود. بدون سه متغیر مدل، سؤال بدون تماس مدل خطا می‌دهد.

۴. نشانی HTTPS سرویس Render را در `BACKEND_URL` فایل Wrangler قرار دهید و منتشر کنید:

```powershell
node gateway/node_modules/wrangler/bin/wrangler.js deploy --config organization_portal/cloudflare/wrangler.toml
```

۵. حساب مدیر کل را از رایانهٔ مورد اعتماد، با همان متغیرهای تولید در محیط موقت
و `RASAM_ORG_LOCAL=0`، با `python organization.py init --email ...` بسازید. این فرمان
مستقیماً از پل خصوصی D1 استفاده می‌کند و به Shell پولی Render نیاز ندارد. رازها
را در نشست امن وارد و بعد از محیط پاک کنید؛ حساب آزمایشی پیش‌نمایش را منتقل نکنید.

۶. ورود، دعوت، دو مرورگر مستقل، لغو مجوز گفتگو، سهمیه، خروج و ماندگاری پس از
بازراه‌اندازی Render را روی استقرار واقعی بررسی کنید. `GET /health` فقط زنده‌بودن
Python را می‌سنجد؛ سلامت D1، مدل یا دسترسی دیتابیس را تضمین نمی‌کند. درخواست
مستقیم `/api/` روی Render باید 403 شود؛ مرورگر فقط از Worker وارد می‌شود.

## اتصال دیتابیس و محدودیت‌های پذیرش

TLS با تأیید گواهی و نام میزبان، حساب فقط‌خواندنی و فهرست منابع هر سه اجباری‌اند.
برای CA خصوصی متن PEM را در فرم بدهید؛ مسیر فایل سرور پذیرفته نمی‌شود. در MySQL
سروری که TLS ندارد پیش از فرستادن رمز رد می‌شود. مقصد را مدیر کل پیش از مدیر
سازمان مجاز می‌کند؛ این فهرست جای firewall و کنترل خروجی شبکه را نمی‌گیرد.

برای دیتابیس اینترنتی، مسیر شبکه و مجوز IP خروجی میزبان لازم است. برای دیتابیس
داخل سازمان، سرور ما باید از VPN یا مسیر خصوصی موجود به آن برسد؛ Render رایگان
خودکار عضو شبکهٔ خصوصی سازمان نیست. ساخت VPN، تونل، بازکردن پورت یا کاهش TLS
در این تغییر انجام نشده است. انتخاب ارائه‌دهنده/مسیر واقعی هر مشتری هنوز لازم است.

سهمیه فقط برای پاسخ کاملاً موفق کم می‌شود: کوئری و خلاصه و در صورت درخواست،
نمودار. شکست، قطع اجرا یا نتیجهٔ ناقص سهمیه را برمی‌گرداند؛ هزینهٔ احتمالی
فراخوانی مدل در حساب ارائه‌دهنده با این بازگردانی حذف نمی‌شود. روز سهمیه UTC است.
درخواست تکراری با همان شناسه، پاسخ ذخیره‌شده را می‌گیرد. هسته برای هر درخواست
در فرایند تازه و حداکثر یک اجرا در هر نمونهٔ میزبان کار می‌کند.

حذف گفتگو دائمی است و مالک آن را انجام می‌دهد. هنوز سیاست زمان‌بندی پاک‌سازی،
پشتیبان‌گیری/بازیابی عملیاتی، بازیابی رمز از طریق ایمیل، مهاجرت تاریخچهٔ محلی و
آزمون بار واقعی تکمیل نشده‌اند؛ پیش از تحویل سازمانی در پلن باقی بمانند.

## بررسی آفلاین

```powershell
python -m pytest tests/organizations tests/databases/mysql/test_tls.py tests/test_architecture.py -q
node --test tests/organizations/worker.test.mjs
```

آزمون D1 از Miniflare نصب‌شده در `gateway/node_modules` استفاده می‌کند. آزمون TLS
یک سرور شبیه‌ساز پروتکل و گواهی محلی دارد؛ آزمون سرویس واقعی مشتری نیست. پاسخ‌های
حساب/گفتگو ساختگی‌اند؛ هیچ‌یک پذیرش مدل واقعی یا دو شبکهٔ مشتری محسوب نمی‌شوند.
