# سایت معرفی و دانلود رصام

نشانی عمومی: https://rasam-product.nova-dd625a.workers.dev

وضعیت ۲۰۲۶/۱۰/۱۸: سایت معرفی منتشر شده است؛ کاربر «فعلاً فقط سایت معرفی» را انتخاب
کرده و فعال‌سازی R2 و دانلود نصب‌کننده معوق‌اند. `DOWNLOAD_URL` سرور لایسنس خالی می‌ماند.

صفحهٔ فارسی و واکنش‌گرا در `public/` است. سرور مستقل `rasam-product` فقط صفحه‌ها و
فایل نصب منتشرشده را ارائه می‌کند؛ به D1 لایسنس، رمز دیتابیس یا کلید مدل وصل نیست.
دانلود با جریان R2 انجام می‌شود؛ فایل نصب بزرگ‌تر از سقف ۲۵ MiB دارایی‌های ثابت است.
سایت تا وجود واقعی شیء نصب‌کننده، دکمهٔ دانلود را فعال نمی‌کند.

فونت سایت وزیرمتن متغیر نسخهٔ 33.003 است و از همین میزبان ارائه می‌شود. فایل اصلی
بدون تغییر و مجوز SIL OFL 1.1 در `public/fonts/` نگه‌داری می‌شوند؛ منبع و انتساب در
`public/fonts/README.txt` آمده است. مرورگر برای بارگذاری فونت به CDN بیرونی وصل نمی‌شود.

## بررسی و پیش‌نمایش

از ریشهٔ پروژه:

```powershell
.\.venv\Scripts\python.exe website/prepare_release.py
node --test website/worker.test.mjs
node gateway/node_modules/wrangler/bin/wrangler.js dev --config website/wrangler.toml --ip 127.0.0.1 --port 8790 --local
```

آماده‌سازی، خروجی بسته را برای فایل‌ها و رازهای ممنوع بررسی می‌کند، هش نصب‌کننده را
با خروجی ساخت تطبیق می‌دهد و فرادادهٔ نسخه و فایل SHA-256 را تولید می‌کند. ورودی‌های
`--installer` و `--bundle` برای مسیر ساخت متفاوت در دسترس‌اند. دادهٔ مشتری، پوشهٔ
`exports/private` و `.env` هرگز جزو دارایی‌های سایت نیستند.

## انتشار

ورود امن Wrangler و دسترسی Workers/R2 باید آماده باشند. برای این میزبان:

```powershell
$env:npm_config_prefix = Join-Path (Get-Location).Path '.codex/tools/cloudflare-auth'
```

فعال‌سازی اولیهٔ اشتراک R2 در داشبورد، پذیرش شرایط و مصرف هزینه‌دار احتمالی دارد و
باید توسط صاحب حساب انجام شود. پس از فعال‌شدن، یک bucket اختصاصی برای انتشار بسازید،
آن را با نام `RELEASES` در `wrangler.toml` متصل کنید و فایل نصب را به `objectKey`
مشخص‌شده در `release.json` بفرستید. bucket لازم نیست عمومی شود؛ Worker فقط کلید
همان نسخه را برای GET/HEAD در دسترس می‌گذارد و ورودی برای بارگذاری عمومی ندارد.

```powershell
node gateway/node_modules/wrangler/bin/wrangler.js deploy --config website/wrangler.toml
```

پس از انتشار، `/release.json` باید `available: true` بدهد. نصب‌کننده را از نشانی عمومی
دوباره دریافت و SHA-256 آن را با فایل ساخت مقایسه کنید. فقط پس از موفقیت این آزمون،
`DOWNLOAD_URL` در `gateway/wrangler.toml` را روی لینک عمومی فایل بگذارید و gateway را
دوباره مستقر کنید. `/version` باید همان نسخه و لینک واقعی را برگرداند.

برای نسخهٔ جدید، فایل نسخهٔ قبلی را جایگزین نکنید؛ نام و کلید نسخهٔ جدید بسازید.
سایت خرید آنلاین، صدور خودکار لایسنس و رابط پرسش‌وپاسخ میزبانی‌شده ندارد. دامنهٔ
اختصاصی را می‌توان پس از اعلام دامنه و دسترسی DNS به همین Worker متصل کرد.
