# پنل خصوصی مدیریت رصام

نام Worker: `rasam-admin`؛ نشانی در `wrangler.toml` تنظیم می‌شود. پنل از سایت عمومی
و Worker مدل جداست و فقط به همان D1 لایسنس متصل می‌شود. کلید مدل یا رمز دیتابیس مشتری
در این Worker وجود ندارد. روش ورود به انتخاب کاربر، نام کاربری و رمز مخصوص پنل است.

## تنظیم اولیه و اجرا

از ریشهٔ پروژه، فقط بار اول:

```powershell
.\.venv\Scripts\python.exe admin_panel/setup_admin.py --username YOUR_EMAIL
```

رمز ۳۲بایتی تصادفی فقط در `exports/private/admin-login.txt` تحویل می‌شود. سرور فقط
PBKDF2-SHA256 با salt تصادفی ۱۶بایتی و ۱۰۰هزار تکرار دارد. این رمز تولیدی عمداً
قابل انتخاب از عبارت‌های کوتاه و قابل حدس نیست. تعداد تکرار با محدودیت بستر Workers
سازگار است؛ افزایش آن باید روی خود سرویس واقعی سنجیده شود. این روش ادعای رعایت
حداقل ۶۰۰هزار تکرار توصیه‌شده برای رمز انسانی در OWASP را ندارد؛ پرآنتروپی‌بودن رمز
تولیدی و محدودیت تلاش ورود الزامی‌اند.

نصب ابزارها و اجرای محلی از پوشهٔ `admin_panel`:

```powershell
npm ci
uv sync --python ../.venv/Scripts/python.exe
uv run pywrangler d1 migrations apply DB --local
uv run pywrangler dev --ip 127.0.0.1 --port 8791 --var ADMIN_ORIGIN:http://127.0.0.1:8791
```

محیط ابزار توسعه Python 3.13 است؛ محیط Pyodide را SDK طبق نسخهٔ خودش می‌سازد.
حالت بدون Secure cookie فقط با نشانی صریح HTTP روی loopback پذیرفته می‌شود؛
پیکربندی عمومی باید HTTPS باشد. پایگاه محلی پنل از پایگاه محلی gateway جداست.

## انتشار

ابتدا مهاجرت افزایشی D1 روی ابر، سپس `uv run pywrangler deploy`. مقدارهای
`ADMIN_USERNAME` و `ADMIN_PASSWORD_HASH` را با `wrangler secret bulk` از stdin
به Worker بدهید؛ متن رمز خام، فایل `.dev.vars` یا فایل تحویل نباید بارگذاری شوند.
ورود امن Wrangler روی این میزبان از `.codex/tools/cloudflare-auth` استفاده می‌کند؛
همان تنظیم `npm_config_prefix` راهنمای gateway لازم است.

## کنترل دسترسی

- نشست ۸ساعته فقط به‌صورت هش در D1؛ کوکی HTTPS با HttpOnly، SameSite=Strict و پیشوند `__Host-`.
- خروج، نشست سرور را حذف می‌کند؛ تغییر تنظیم نام کاربری یا هش رمز، نشست‌های قبلی را نامعتبر می‌کند.
- حداکثر پنج تلاش ورود هر IP در پنجرهٔ پنج‌دقیقه‌ای و سقف کل تلاش‌ها؛ شمارنده‌های D1 اتمی‌اند.
- درخواست تغییردهنده باید Origin همان پنل و توکن CSRF متعلق به نشست را داشته باشد.
- صفحهٔ ورود عمومی است؛ خود صفحهٔ پنل و API فهرست، بدون نشست داده‌ای نمی‌دهند.
- پاسخ‌های مدیریتی cache نمی‌شوند؛ ورود با کد لایسنس مشتری یا هدر ایمیل ساختگی ممکن نیست.

## چرخش یا بازیابی رمز مدیر

از ابزار تنظیم، رمز ضعیف دلخواه وارد نکنید. برای چرخش، ابتدا فایل‌های موجود
`.dev.vars` و تحویل خصوصی را به محل امن دیگری منتقل کنید؛ ابزار تنظیم را دوباره
با همان نام کاربری اجرا و هش تازه را با secret bulk منتشر کنید. پس از تأیید ورود،
نسخهٔ قبلی فایل رمز را طبق سیاست نگه‌داری امن خود کنار بگذارید. لینک بازیابی عمومی،
ثبت‌نام عمومی و مدیر دوم در این نسخه وجود ندارند.

## مدیریت لایسنس

پس از ورود، «صدور لایسنس» نام مشتری، مدت ۳۰/۳۶۵ روز و سهمیهٔ روزانه را می‌گیرد.
کد خام فقط همان بار در پنجرهٔ خصوصی نمایش/کپی می‌شود؛ بستن پنجره یا ترک صفحه آن را
از رابط پاک می‌کند. کد خام در D1، رویدادها یا localStorage ذخیره نمی‌شود.

برای هر ردیف، «تمدید» تعداد روز را به تاریخ دیرتر بین امروز و پایان اعتبار فعلی
اضافه و لایسنس را فعال می‌کند. «تغییر سهمیه» شمارندهٔ مصرف امروز را صفر نمی‌کند.
«ابطال» نیاز به تأیید مشتری هدف دارد و درخواست‌های تازه را رد می‌کند؛ فعال‌سازی
دوباره با تمدید ممکن است. رویدادها شامل مدیر، زمان، نوع عمل و مشتری‌اند.

هر بار بازکردن فرم یک UUID تازه دارد؛ تکرار ارسال همان فرم دوباره اثر نمی‌کند.
عمل و ثبت رویداد با D1 `batch` یک تراکنش‌اند؛ خطای ثبت رویداد تغییر را هم برمی‌گرداند.
اگر ارتباط پس از صدور قطع شود و کد خام نرسد، ارسال دوباره همان فرم لایسنس دوم
نمی‌سازد؛ نتیجهٔ ثبت‌شده را بررسی کنید. کد قبلی بازیابی نمی‌شود؛ در صورت نیاز آن
لایسنس را باطل و از فرم تازه کد جایگزین صادر کنید.

ابزار خط فرمان از همان `gateway/license_commands.py` استفاده می‌کند و دستور
`python -m gateway.admin --remote quota HASH --daily-limit N` نیز برای پشتیبانی دارد.
فهرست فعالیت‌ها، عملیات پنل را ثبت می‌کند؛ فعالیت مستقیم CLI فعلاً در آن نیست.

منابع: [WebCrypto در Workers](https://developers.cloudflare.com/workers/runtime-apis/web-crypto/)،
[نگه‌داری رمز در OWASP](https://cheatsheetseries.owasp.org/cheatsheets/Password_Storage_Cheat_Sheet.html).

## مدیریت پلن‌ها

سه پلن اولیه پیش‌نویس‌اند. در بخش پلن‌ها، مدل معتبر سرویس فعلی، ظرفیت فراخوانی روزانه UTC و قیمت به تومان را تعیین کنید و نمایش در سایت را روشن کنید. قیمت خالی آن دوره را حذف می‌کند. تغییر پلن فقط بر صدور جدید اثر دارد؛ پرداخت واقعی فعلاً غیرفعال است.
