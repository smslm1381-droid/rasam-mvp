# بررسی پنل مدیریت رصام — ۲۰۲۶/۱۰/۱۸

قدم‌های ۳۹ و ۴۰ روی [پنل عمومی](https://rasam-admin.nova-dd625a.workers.dev)
منتشر شدند. پنل خصوصی است؛ عمومی‌بودن نشانی مجوز دسترسی نمی‌دهد.
[راهنمای مدیر](../admin_panel/README.md) تنظیم، استفاده و بازیابی دسترسی را توضیح می‌دهد.

## نتیجهٔ آزمون‌ها

| بررسی | نتیجهٔ واقعی |
|---|---|
| اجرای کامل `python -m pytest -q --tb=short` با Worker محلی در `RASAM_GATEWAY_TEST_URL` | PASS؛ ۹۵۱ موفق، صفر شکست/خطا/skip، ۱۳۷٫۰۱ ثانیه |
| D1 واقعی شبیه‌سازی‌شده با Miniflare | PASS؛ نشست، محدودیت ورود، CSRF، اعتبارسنجی، سهمیه و رویداد |
| ارسال هم‌زمان چهار درخواست صدور با یک UUID | PASS؛ یک لایسنس، یک رویداد و یک پاسخ دارای کد خام |
| شکست درج رویداد و rollback تغییر لایسنس | PASS؛ عملیات ناقص ثبت نمی‌شود |
| چرخهٔ واقعی روی Cloudflare/D1 | PASS؛ صدور، تکرار بی‌اثر، تمدید، سهمیه، ابطال و فعال‌سازی دوباره |
| فعال‌سازی با هستهٔ رومیزی و تماس واقعی سرویس مدل | PASS؛ پاسخ مدل HTTP 200، پس از ابطال رد لایسنس |
| ورود/خروج و دسترسی بدون نشست | PASS؛ درخواست بعد از خروج رد می‌شود؛ صفحه و API خصوصی محافظت می‌شوند |
| فرم‌های فارسی در مرورگر | PASS؛ صدور، تمدید، سهمیهٔ ۱۲ به ۷ و ابطال با تأیید؛ چهار رویداد دیده شدند |
| نمای موبایل ۳۹۰×۸۴۴ | PASS؛ وزیرمتن محلی، بدون سرریز افقی صفحه؛ جدول اسکرول مستقل دارد |
| سایت محصول و سلامت gateway | PASS؛ لینک ورود مدیریت منتشر و سلامت gateway برابر HTTP 200 |
| پاک‌سازی دادهٔ پذیرش | PASS؛ فقط لایسنس‌ها و رویدادهای مشخص آزمایشی محلی/عمومی حذف شدند؛ لایسنس شخصی حفظ شد |

شواهد محلی نادیده‌گرفته‌شده در `exports/`: گزارش و XML آزمون `admin-panel-pytest.*`،
نتایج `admin-step40-local.json`، `admin-step40-live.json` و `admin-step40-browser.json`،
تصویر چرخهٔ فرم‌ها `admin-panel-operations.png` و تصاویر نهایی پنل و موبایل.
مقادیر رمز یا کد خام در این گزارش و فایل‌های نتیجه ثبت نشده‌اند.

اجرای نخست مجموعه یک شکست به‌علت CRLF راهنمای رومیزی داشت؛ فقط پایان خط همان فایل
اصلاح شد، بررسی‌های بسته‌بندی و سپس کل مجموعه دوباره اجرا شدند. نتیجهٔ نهایی بالا
مربوط به اجرای کامل دوم است. در قدم ۳۹ نیز خطای تبدیل پاسخ فایل در Python Workers
در مرورگر کشف و اصلاح، آزمون رگرسیون اضافه و رمز آزمایشی اولیه تعویض شد.

## مرز پذیرش

این آزمون از هستهٔ فعال‌سازی رومیزی استفاده کرد؛ نصب روی Windows 10/11 تازه و
تمرین مستقل کاربر غیرفنی را جایگزین نمی‌کند. آن پذیرش‌ها و دیتابیس شبکهٔ واقعی
مشتری همچنان در `PLAN.md` بازند. دانلود عمومی نصب‌کننده و R2 به انتخاب کاربر معوق‌اند.

پنل یک مدیر دارد؛ پرداخت آنلاین، ثبت‌نام عمومی، مدیر دوم و تغییر کلید مدل در رابط
ساخته نشده‌اند. فعالیت‌های مستقیم CLI در فهرست رویدادهای پنل ثبت نمی‌شوند.
کد صادرشده بازیابی نمی‌شود؛ در صورت نرسیدن پاسخ، تکرار همان درخواست لایسنس دوم
نمی‌سازد و راهنمای جایگزینی کد در README پنل آمده است. آزمون موفق فعلی تضمین ظرفیت
تجاری سرویس مدل یا آزمون بازیابی پشتیبان D1 نیست.
