# راهنمای پشتیبانی نسخهٔ رومیزی

وضعیت: نسخهٔ آزمایشی `0.1.1`، سرویس عمومی Cloudflare فعال، نصب‌کننده بدون امضا.
این سند جای دانش دامنهٔ مشتری را نمی‌گیرد. تمرین کاربر غیرفنی روی Windows 10/11 تازه
هنوز انجام نشده؛ هنگام تمرین، هر کمک واقعی را در جدول انتهای سند ثبت کنید.

## برگهٔ تحویل به کاربر

پیش از جلسه، فایل نصب و SHA-256 همان فایل، کد لایسنس، نوع دیتابیس، نام دیتابیس،
نام سرور، درگاه، کاربر فقط‌خواندنی، رمز و یک پرسش با پاسخ بررسی‌شده آماده باشند.
رمز و لایسنس را از کانال خصوصی تحویل دهید و در گزارش تمرین ننویسید.
راهنمای کاربر: [اولین پاسخ](desktop-quickstart.md).
فایل و هش محلی ساخت فعلی در `exports/windows-build/` هستند؛ پیوند دانلود عمومی
هنوز منتشر نشده است. پیش از تحویل، هش را دوباره با `Get-FileHash` بسنجید.

```powershell
Get-FileHash .\RasamSetup.exe -Algorithm SHA256
```

نسخهٔ آزمایشی امضا ندارد. برای فایل با منشأ و هش تأییدشده، در هشدار آبی SmartScreen
کاربر می‌تواند خودش `More info` و سپس `Run anyway` را انتخاب کند. اگر سازمان گزینه
را بسته یا هشدار تشخیص بدافزار است، بررسی با مسئول فنی است؛ تنظیم امنیتی را خاموش
نکنید. تصویر واقعی هشدار هنوز در ویندوز تازه ثبت نشده است.
[منبع Microsoft](https://github.com/MicrosoftDocs/windows-dev-docs/blob/docs/hub/apps/package-and-deploy/publish-first-app.md).

نام سرویس: `https://rasam-gateway.nova-dd625a.workers.dev`.
آزمایش سلامت و نسخه، بدون رمز و بدون مصرف سهمیه:

```powershell
Invoke-RestMethod https://rasam-gateway.nova-dd625a.workers.dev/health
Invoke-RestMethod https://rasam-gateway.nova-dd625a.workers.dev/version
```

سلامت باید `status=ok` باشد. نسخهٔ فعلی `0.1.1` است؛ تا انتشار فایل واقعی،
`download_url` خالی است. پس از انتشار، طبق [راهنمای Worker](../gateway/README.md)
مقدار `DOWNLOAD_URL` را تنظیم کنید؛ نشانی سرویس مدل جای نشانی Worker نیست.

## ساخت کاربر فقط‌خواندنی

این دستورها را مسئول دیتابیس با دسترسی مدیریت روی **دیتابیس هدف** اجرا می‌کند؛
حساب مدیر را به رصام ندهید. نام دیتابیس و میزبان نمونه را جایگزین کنید.
برای دیتابیس موجود مشتری، اسکریپت‌های `seed_*` پروژه را اجرا نکنید؛ برای دمو هستند
و دادهٔ قبلی هم‌نام را جایگزین می‌کنند.

### MongoDB

با `mongosh` به سرور مدیریتی وارد شوید؛ رمز را در اعلان ابزار وارد کنید:

```text
mongosh --host SERVER --port PORT --username ADMIN --authenticationDatabase admin --password
```

در پوسته، `YOUR_DATABASE` را عوض کنید:

```javascript
db.getSiblingDB("YOUR_DATABASE").createUser({
  user: "rasam_reader",
  pwd: passwordPrompt(),
  roles: [{role: "read", db: "YOUR_DATABASE"}]
});
```

کاربر در خود دیتابیس ساخته می‌شود؛ فرم اتصال همان نام دیتابیس را می‌گیرد.
اگر کاربر از قبل وجود دارد، نقش‌هایش را مسئول دیتابیس بررسی کند؛ حساب را خودکار
حذف یا بازنویسی نکنید. رصام هم نقش حساب و هم فهرست منابع مجاز را بررسی می‌کند.

### MySQL / MariaDB

```text
mysql --host=SERVER --port=PORT --user=ADMIN --password
```

در پوسته، `CLIENT_HOST` را به میزبان مجاز مشتری، `YOUR_DATABASE` را به نام دیتابیس
و رمز نمونه را به رمز واقعی قوی تغییر دهید:

```sql
CREATE USER 'rasam_reader'@'CLIENT_HOST' IDENTIFIED BY 'REPLACE_WITH_A_STRONG_PASSWORD';
GRANT SELECT ON `YOUR_DATABASE`.* TO 'rasam_reader'@'CLIENT_HOST';
SHOW GRANTS FOR 'rasam_reader'@'CLIENT_HOST';
```

خروجی باید فقط مجوز خواندن موردنیاز را نشان دهد؛ نقش یا مجوز نوشتن اضافی پذیرفته نیست.
از میزبان محدود مشتری استفاده کنید. اگر حساب موجود است، تغییر نقش‌ها را مسئول دیتابیس
انجام دهد. دستور آمادهٔ داخل رابط نیز مطابق آداپتور تولید می‌شود.

## اتصال شبکه و خطاهای رایج

دیتابیس داخلی باید از کامپیوتر مشتری قابل دسترس باشد، نه از Cloudflare؛ Worker
به دیتابیس مشتری وصل نمی‌شود. برای اتصال اینترنتی، مسیر شبکه و TLS را مسئول فنی
فراهم کند؛ برای تمرین، دیتابیس توسعه را عمومی نکنید. روی ویندوز مشتری:

```powershell
Test-NetConnection SERVER -Port PORT
```

`TcpTestSucceeded=True` فقط بازبودن مسیر است و درستی رمز یا مجوز را ثابت نمی‌کند.

| پیام | اقدام پشتیبانی |
|---|---|
| سرور پیدا نشد | نام سرور، DNS و VPN لازم را بررسی کنید |
| درگاه بسته است / زمان اتصال تمام شد | مسیر شبکه، درگاه و فایروال سرور را بررسی کنید |
| نام کاربری یا رمز پذیرفته نشد | رمز و در Mongo محل ساخت کاربر، در MySQL میزبان مجاز حساب را بررسی کنید |
| دیتابیس پیدا نشد یا اجازه ندارید | نام دیتابیس و مجوز همان دیتابیس را بررسی کنید |
| حساب فقط‌خواندنی لازم است | حساب جدا با دستورهای بالا بسازید؛ گارد را خاموش نکنید |
| لایسنس نامعتبر، منقضی یا باطل است | وضعیت D1 را بررسی و در صورت مجازبودن تمدید کنید؛ نصب دوباره راه‌حل نیست |
| سهمیه تمام شده | سهمیهٔ لایسنس و محدودیت ارائه‌دهنده دو چیزند؛ هر سؤال می‌تواند چند درخواست مدل داشته باشد |
| سرویس مدل پاسخ نمی‌دهد | سلامت Worker و تنظیمات secrets مدل را بررسی کنید؛ خطای خام حاوی رمز را منتشر نکنید |
| عدد غلط یا معنی ستون نامشخص | با مسئول داده، آموزش و سؤال طلایی را کامل کنید؛ از حدس مدل به‌عنوان مرجع استفاده نکنید |

مدیریت لایسنس از ریشهٔ پروژه، با محیط Python و ورود امن Wrangler آماده:

```powershell
python -m gateway.admin --remote new CUSTOMER --plan monthly
python -m gateway.admin --remote list
python -m gateway.admin --remote extend HASH_FROM_LIST --days 30
python -m gateway.admin --remote revoke HASH_FROM_LIST
```

کلید خام فقط هنگام صدور نمایش داده می‌شود. برای تمدید و ابطال از هش فهرست استفاده
کنید. روی این میزبان، بستهٔ keyring در `.codex/tools/cloudflare-auth` نصب محلی دارد؛
در صورت نیاز از ریشهٔ همین checkout، پیش از دستورها مسیر محلی را تنظیم کنید:

```powershell
$env:npm_config_prefix = Join-Path (Get-Location).Path '.codex/tools/cloudflare-auth'
```

روی سیستم دیگر، نصب و ورود امن را مطابق `gateway/README.md` انجام دهید.
مقدار راز را در فرمان یا سند عمومی ننویسید.

## سنجه و پایان جلسه

همان سؤال‌های `golden_questions.yaml` از مسیر انتخابی نمره می‌گیرند؛ همهٔ ۱۵ سؤال
باید واقعاً سنجیده شوند. خطای سرویس ارزیابی را ناقص و exit code را ناموفق می‌کند.
مدل واقعی و سهمیه لازم است؛ `--pause 20` بین سؤال‌ها فاصله می‌دهد و محدودیت روزانه
را رفع نمی‌کند. برای آزمون طولانی، سهمیهٔ لایسنس آزمایشی را متناسب تعیین کنید.
[محدودیت‌های مدل‌های رایگان OpenRouter](https://openrouter.ai/pricing) از سهمیهٔ D1
جداست؛ تغییر کلید در همان حساب را معادل افزایش ظرفیت حساب فرض نکنید. پس از تغییر
اتصال مدل در `.env`، secrets سرور واسط نیز باید از مسیر امن هماهنگ شوند؛ کلید مدل
وارد نسخهٔ نصب‌شده نمی‌شود.

```powershell
python scripts/evaluate.py --api-url http://127.0.0.1:8000 --pause 20
python scripts/evaluate.py --desktop-home "$env:APPDATA\Rasam" --pause 20
```

در مسیر API کلید از `RASAM_API_KEY` محیط/`.env` خوانده می‌شود. در مسیر رومیزی،
برنامه باید باز باشد؛ توکن نشست از پوشهٔ داده خوانده می‌شود و در آرگومان نمی‌آید.
پروفایل انتخابی محیط توسعه باید همان مشتری برنامهٔ مقصد باشد؛ برای دموهای متفاوت
`RASAM_CUSTOMER=demo` یا `demo-mysql` را مطابق مقصد انتخاب کنید.

پس از اولین پاسخ، یک بار خروج و بازکردن، خروجی CSV/Excel مجاز، تمدید، ارتقا و حفظ
آموزش را امتحان کنید. برای حذف برنامه از Installed apps ویندوز استفاده کنید؛ دادهٔ
`%APPDATA%\Rasam` و Credential Manager عمداً باقی می‌مانند. پاک‌کردن داده و انتقال
رمز به سیستم دیگر کار جدا با هماهنگی صاحب داده است.
