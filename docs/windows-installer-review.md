# پذیرش نصب‌کنندهٔ آزمایشی ویندوز

تاریخ: ۲۰۲۶/۱۰/۱۷. ساخت اولیه `0.1.0` و نسخهٔ فعلی `0.1.1`.
نصب‌کننده بنا به تصمیم ۱۰۵ بدون امضا است.

## شواهد ثبت‌شده

- اجرای کامل پروژه: **۹۰۶ تست موفق، بدون شکست و بدون skip** در ۱۸۳٫۳۶ ثانیه؛
  گزارش محلی `exports/step36-pytest.xml`. زیرساخت واقعی MongoDB، MySQL، D1 محلی
  و Python Worker در دسترس بودند. سهمیهٔ مدل با اجرای دوبارهٔ سنجه مصرف نشد.
- PyInstaller 6.22.3، Python 3.13.16 و Inno Setup 6.7.3 روی همین ویندوز.
  بستهٔ پوشه‌ای حدود ۱۹۰ MiB است. کامپایلر Inno از انتشار رسمی دریافت و SHA-256
  و امضای معتبر سازنده بررسی شد؛ این به معنی امضاشدن خروجی رصام نیست.
- نصب واقعی در مسیر آزمایشی، بدون نیاز به Administrator؛ اجرای فایل نصب‌شده
  با PATH محدود به System32 و بدون Python. فعال‌سازی، Windows Credential Manager،
  Worker/D1 محلی، مدل واقعی و اجرای کوئری محافظت‌شدهٔ Mongo موفق بود. میانگین
  `28.60765672670013` به دست آمد؛ خروجی محلی `exports/step36-installed-answer.json`.
- اجرای دوباره همان نشست را استفاده کرد؛ درخواست خروج بدون توکن و از Origin بیگانه
  رد شد و خروج مجاز فرایند را بست. اجرای فایل frozen نیز جداگانه موفق بود.
- حذف واقعی نصب آزمایشی فایل اجرایی را پاک کرد؛ فایل آزمایشی AppData و راز آزمایشی
  Credential Manager باقی ماندند. فقط همان دو شاهد آزمایشی پس از بررسی پاک شدند.
- بررسی محتوای بسته، فایل مشتری و `.env` و `.dev.vars` را ممنوع می‌کند؛ اسکن باینری
  نیز نبود مقدار واقعی کلیدها و رمزهای پیکربندی را بررسی می‌کند.

## سرویس عمومی

Worker: `https://rasam-gateway.nova-dd625a.workers.dev`، نام `rasam-gateway`.
نسخهٔ استقرار اولیه: `54978f4b-a223-4991-8033-c2c5f23749c4`.
پایگاه مستقل `rasam-licenses` ساخته و مهاجرت `0001_licenses.sql` اعمال شد.
شناسه در `gateway/wrangler.toml` ثبت است. کلید مدل و نشانی و نام مدل به‌صورت
secrets سرور ثبت شدند؛ در مخزن یا نصب‌کننده نیستند. ورود Wrangler در انبار امن
سیستم ذخیره شد. `/health` پاسخ ۲۰۰ و کلید نامعتبر پاسخ ۴۰۱ داد.

نصب‌کننده با همین نشانی بازسازی و دوباره نصب شد؛ فعال‌سازی و پرسش واقعی روی Worker
عمومی نیز با همان مقدار عددی درست موفق شد. خروجی محلی:
`exports/step36-public-installed-answer.json`. لایسنس و رازهای آزمایشی پس از بررسی
پاک شدند. SHA-256 نسخهٔ `0.1.0`:
`27b61ecb96e50a40b849ea5b5441a24345f15e2f33d49c79be7e839143ff6817`.
اشکال مدیریت D1 ابری در `--file --json` اصلاح شد؛ مسیر کوتاه `--command` نتیجهٔ
JSON و RETURNING را حفظ می‌کند و فقط هش لایسنس را در SQL می‌گیرد.

## موارد باز

این میزبان محیط تازه و فاقد Python نیست؛ محدودکردن PATH فقط استقلال بسته از Python
نصب‌شده را می‌سنجد. آزمون کامل روی Windows 10 و Windows 11 تازه، تصویر واقعی هشدار
SmartScreen و تمرین کاربر غیرفنی همچنان بازند. گردش‌کار GitHub Actions نوشته شده
ولی اجرا نشده است. کاربر تعویق آزمون محیط تازه تا تحویل نهایی را صریحاً تأیید کرد؛
