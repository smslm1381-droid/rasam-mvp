# استقرار آزمایشی رصام روی Ubuntu

این راهنما ادامهٔ سرور آزمایشی موجود است؛ برنامهٔ دوم پوشه، محیط، کاربر سیستم،
سرویس systemd و پورت داخلی جدا خواهد داشت. هیچ سرویس چتی هنوز عمومی نشده است.

## آنچه آماده است

- Ubuntu 24.04، پروژه در `/opt/rasam` و محیط `.venv`.
- MongoDB در کانتینر `rasam-mongo` با volume مستقل `rasam_mongo_data` و
  پورت `127.0.0.1:27017`؛ پورت دیتابیس نباید عمومی شود.
- چهار کالکشن تله‌متری و حساب `rasam_ro` با نقش `read`.
- `.mongo-app.env` برای اتصال برنامه و `.license.env` برای لایسنس؛ هر دو
  خصوصی‌اند. `.mongo.env` مخصوص مدیر دیتابیس است و وارد محیط برنامه نمی‌شود.

## دریافت نسخهٔ جدید

روی خود سرور، نه PowerShell ویندوز:

```bash
cd /opt/rasam
git status --short
git pull --ff-only
.venv/bin/python -m pip install -r requirements.txt
```

این دستورها کد و وابستگی‌ها را به‌روز می‌کنند؛ تنظیمات موجود `.env` خودکار
تغییر نمی‌کند. در صورت تعارض، فایل یا دیتابیس را پاک نکنید.

## تنظیم اجرای دارای لایسنس

مقدارهای زیر در `.env` خصوصی سرور لازم‌اند؛ نمونه‌ها را با راز واقعی در
ترمینال یا گفتگوی عمومی چاپ نکنید:

```dotenv
RASAM_CUSTOMER=demo
RASAM_MONGO_URI=<اتصال فقط‌خواندنی از .mongo-app.env>
RASAM_LLM_API_KEY=<لایسنس موجود در .license.env>
RASAM_LLM_BASE_URL=https://rasam-gateway.nova-dd625a.workers.dev/v1
RASAM_LLM_MODEL=gemma-3-27b-it
RASAM_LLM_REASONING_EFFORT=unset
RASAM_LLM_MAX_TOKENS=1024
RASAM_LLM_TIMEOUT_MS=90000
RASAM_VERBOSE=0
RASAM_API_KEY=<کلید تصادفی مستقل برای API برنامه>
```

مجوز فایل `600` و مالک آن کاربر سرویس باشد. کلید سرویس GapGPT فقط در واسط
Cloudflare می‌ماند؛ `.env.example` ریشه مخصوص اتصال مستقیم توسعه است و نباید
کورکورانه جای تنظیمات اجرای دارای لایسنس کپی شود.

پیش از تست، `/license/status` را با لایسنس موجود از همین سرور بخوانید و مدل
واقعی و اعتبار را تأیید کنید. نتیجهٔ `GET /health` سلامت واسط است و موفقیت مدل
را اثبات نمی‌کند. روی این سرور HTTP/1.1 قبلاً پاسخ موفق داده است.

## آزمون کامل پیش از انتشار

```bash
cd /opt/rasam
.venv/bin/python ask.py --query "آخرین زمان ثبت توان DC اینورتر را به صورت تاریخ میلادی و ساعت UTC نشان بده و مقدار توان DC همان رکورد را هم بگو."
```

این درخواست از گراف واقعی، گارد، اتصال فقط‌خواندنی و خلاصه‌سازی عبور می‌کند.
برای دیتاست فعلی انتظار زمان `2026-06-08 11:41:48 UTC` و مقدار `59108` داریم؛
وجود عدد درست در جدول جای بررسی خلاصه را نمی‌گیرد. شکست مدل را شکست استقرار
دیتابیس حساب نکنید و واردکردن داده را دوباره اجرا نکنید.

## مرحلهٔ بعد از تأیید آزمون

سرویس با کاربر غیر root و systemd روی پورت داخلی مستقل اجرا شود؛ Nginx دامنهٔ
رصام را به آن هدایت کند و HTTPS پیش از ورود کاربران فعال باشد. برای برنامهٔ
دوم سرویس، پورت و دامنهٔ دیگر اضافه می‌شود. نسخهٔ رومیزی را با حذف محدودیت
localhost عمومی نکنید؛ رابط سازمانی و احراز هویت آن پذیرش و تنظیم جدا می‌خواهد.
پذیرش دامنه، TLS، حساب وب و جداسازی گفتگوها هنوز با صرف اجرای CLI تکمیل نمی‌شود.
